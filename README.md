## 👀 서비스 소개

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/025cceb9-797a-4267-89d5-9b98beff484f" />

MSA기반 Full stack 개발 교육과정에서 진행했던 최종 프로젝트

기존의 CMS+ 스퀘어 사업의 온라인 간편 주문 서비스는 쇼핑몰이 없는 기업이나 소상공인도 쉽게 사용할 수 있는 주문 및 결제 솔루션입니다. 이 서비스는 온라인 주문서 링크를 생성하고, 이를 다양한 채널에 배포해 고객들이 정기배송이나 단건배송을 선택하고 결제할 수 있도록 돕습니다.

**기획 의도**

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/a116a31e-376c-4741-82ec-92d556fa8bb9" />
ClickNBuy는 사용자 참여율을 좀 더 높이기 위해 PWA(Progressive Web App) 기능을 추가로 도입했습니다. 이를 통해 고객들이 웹과 모바일 앱 환경에서 동일한 경험을 할 수 있습니다.
이로써 접근성을 높이고 주문 과정을 더욱 간편하게 만들어 재주문율과 고객 만족도를 향상시키고자 했습니다.

해당 프로젝트에서 주소, 결제수단, 대시보드 도메인을 도맡아서 개발을 진행했으며, 맡은 도메인의 프론트엔드와 백엔드 모두 구현해보며 전반적인 개발의 흐름을 이해할 수 있었습니다.
